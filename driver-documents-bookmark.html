DRIVER DOCUMENTS BOOKMARK

Saves a starter's documents from Warrior Ops straight into a new named driver folder, in the right sub-folders.

  1. Show your bookmarks bar in Chrome (Ctrl+Shift+B).
  2. Drag this button up onto the bookmarks bar:
    DRIVER DOCS
  3. Skip the Hub folder button — this makes the folder for you.
  4. On Warrior Ops open the starter, then the Documents tab, so the list with the View links is showing.
  5. Click DRIVER DOCS, confirm the starter's name, pick the folder where starters live (once per starter), press OK — it creates the named folder with its 5 sub-folders and saves everything in.
